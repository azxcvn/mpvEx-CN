# mpvEx-CN v1.3.2（同步上游 v1.3.0）

## 版本说明

- GitHub Tag：v1.0.7（仅用于仓库内区分版本）
- 汉化版 APP 实际版本号：1.3.2（可覆盖安装）
- 上游官方版本：1.3.0

---

## 更新内容（同步上游 v1.3.0）

### 播放器
- 新增画面比例记忆：设置一次，之后自动沿用
- 主字幕关闭时，次要字幕自动移到底部
- 优化播放器启动速度与播放进度记录方式
- 改善拖动进度条的稳定性与内存占用
- 重新设计标题栏与 A-B 循环按钮；控制按钮文字改用等宽字体
- 去除进度条上章节标记之间的空隙

### 媒体库与文件浏览
- 重构媒体扫描：改为单次遍历、树形视图改为响应式（树形视图功能保留）
- 新增流式 JSON 缓存 + 文件系统时间戳跟踪，浏览文件夹明显更快
- 预读内存视频缓存、延后后台同步，打开视频列表更跟手
- 缩略图延后生成，磁盘解码改用 RGB_565，更省内存
- 「关于」页集成 AboutLibraries v15，可正常查看开源许可

### 修复
- 不同文件夹里的同名文件不再共用播放历史
- 删除视频后应用内外数据不一致（现已自动对账）
- 删除视频时不再误删同名的外部字幕文件
- 选择章节后章节面板不再跳回顶部
- 「新」标签视频数量与文件夹计数错误、返回时不刷新
- 打开视频列表时不再短暂闪出空状态
- 浏览页顶栏圆角统一；下拉刷新改用 Material 3 Expressive 加载动画

### 移除的功能（跟随上游）
- 氛围模式（Ambient Mode）
- Lua 脚本 / 自定义 Lua 按钮
- 在线字幕搜索（Wyzie）及相关设置项
- 自定义按钮（Custom Buttons）
- 应用不再内置 Google Sans Flex 字体，改用系统默认字体（安装包更小）

## 汉化版说明

- 界面与文案已全部汉化（本次又补全了一批残留的硬编码英文）
- 移除捐赠相关模块
- 禁用自动更新

## 安装说明

- 近几年绝大多数手机请装 **arm64-v8a**
- 只有较老的 32 位设备才需要 **armeabi-v7a**
- 可直接覆盖安装 1.3.1 及之前由同一签名发布的版本；若提示签名不一致，请先卸载旧版再装
- 请勿使用应用内的「检查更新」，升级后会丢失汉化
